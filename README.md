# GIST 학식 알림

GIST 제1·제2학생식당 게시판에서 **오늘의 아침·점심·저녁 식단**을 찾아 정해진 시각에 **메모장으로 화면에 띄워 주고**, 원하면 **카카오톡 '나와의 채팅'으로도 보내 주는** 프로그램입니다.

- 기본 알림 시각: 아침 08:00 · 점심 11:30 · 저녁 17:30 (설치할 때 바꿀 수 있음)
- 식단표는 게시글에 첨부된 이미지/PDF라서, Claude가 표를 읽어 오늘 칸만 뽑아냅니다.

```
GIST 오늘의 점심식단
2026년 10월 22일 (목)

[제1학생식당]
  <일품>
    - 숯불맛고기국수
    - 타코야끼
  <한식>
    - 백미밥
    - 콩나물국
    ...
```

---

## 1. 준비물

| 필요한 것 | 설명 |
|-----------|------|
| **Windows PC** | 메모장 알림과 작업 스케줄러를 사용합니다. |
| **Python 3.10 이상** | [python.org](https://www.python.org/downloads/)에서 설치. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요. |
| **Claude Code** | [claude.com/claude-code](https://claude.com/claude-code) 안내대로 설치한 뒤, 터미널(명령 프롬프트)에서 `claude`를 한 번 실행해 **로그인**해 두세요. 식단표를 읽을 때 본인 계정 사용량이 조금씩 듭니다(끼니당 1회). |
| Git for Windows (권장) | [git-scm.com](https://git-scm.com). 함께 설치되는 `pdftotext`로 식단표 글자를 교차 확인해 정확도가 올라갑니다. 없어도 동작합니다. |

## 2. 설치

1. 이 폴더를 원하는 위치에 둡니다(예: `문서\gist-meal`). **설치 후 폴더를 옮기면 install.cmd를 다시 실행**해야 합니다.
2. 폴더 안의 **`install.cmd`를 더블클릭**합니다.
3. 질문에 답합니다. 그냥 Enter를 누르면 [ ] 안의 기본값이 선택됩니다.
   - 받을 끼니와 시각
   - **로그인하지 않아도 실행할지** (→ [4-1](#4-1-로그인하지-않아도-받기-선택) 참고)
   - 카카오톡으로도 받을지 (→ [3. 카카오톡 설정](#3-카카오톡-설정-선택) 먼저 해 두세요)
   - 지금 테스트 실행할지 → 1~2분 뒤 메모장이 뜨면 성공입니다.

> Windows가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

## 3. 카카오톡 설정 (선택)

내 카톡으로만 보낼 수 있습니다(카카오 정책상 친구·단톡방 전송은 별도 심사 필요). **각자 자기 카카오 앱을 만들어야 합니다.** 10분 정도 걸립니다. 콘솔 화면 구성이 조금 다를 수 있으니 비슷한 메뉴를 찾아 주세요.

1. [developers.kakao.com](https://developers.kakao.com) → 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
   - 앱 이름: 아무거나(예: `GIST 식단`), 회사명: 본인 이름 등
2. **카카오 로그인** 메뉴
   - 활성화 설정 **ON**
   - **Redirect URI**에 정확히 `http://localhost:8765/callback` 등록
3. **카카오 로그인 → 동의항목** → **카카오톡 메시지 전송** → **선택 동의**로 설정
4. **플랫폼 → Web** → 사이트 도메인에 `https://www.gist.ac.kr` 추가 (메시지의 "식단표 보기" 버튼용)
5. **앱 키**에서 **REST API 키** 복사. **보안(Client Secret)** 이 "사용함"이면 그 코드도 복사
6. `install.cmd`를 실행해 "카카오톡으로도 받을까요?"에 `y` → 키 입력 → 브라우저에서 로그인·동의
7. 카톡 '나와의 채팅'에 테스트 메시지가 오면 완료

로그인 정보는 이 폴더의 `.secrets\kakao.json`에만 저장되고 자동으로 갱신됩니다. 약 2개월간 한 번도 실행되지 않으면 만료되니 그때는 install.cmd를 다시 실행하세요.

## 4. 사용

- 설치가 끝나면 정해진 시각마다 자동으로 실행됩니다. 기본 설정에서는 **그 시각에 PC가 켜져 있고 로그인된 상태**여야 합니다(꺼져 있던 끼니는 건너뜀).
- 지난 결과: `output\` 폴더 (`lunch_2026-10-22.txt` 등)
- 실행 기록: `logs\` 폴더
- 지금 바로 받아 보기: 폴더에서 명령 프롬프트를 열고 `run_meal.cmd lunch` (breakfast / lunch / dinner)
- Claude Code 대화에서 이 폴더를 열고 "오늘 점심 뭐야?"라고 물어도 됩니다(이때는 카톡을 보내지 않습니다).

### 4-1. 로그인하지 않아도 받기 (선택)

설치 중 "PC에 로그인하지 않아도 실행할까요?"에 `y`라고 답하면, **전원만 켜져 있으면** 로그인 화면 상태에서도 식단을 읽어 카카오톡으로 보냅니다.

- 설치할 때 **관리자 승인(사용자 계정 컨트롤 → [예])** 이 한 번 필요합니다.
- 로그인하지 않은 동안에는 화면이 없으므로 **알림은 카카오톡으로만** 옵니다. 카카오톡 설정을 함께 해 두세요.
- 그 시각에 로그인되어 있으면 메모장도 함께 뜹니다(작업 `GIST-…-Popup`).
- PC가 **절전 모드**면 깨워서 실행합니다. 단, **완전히 꺼져 있거나 최대 절전(하이버네이트)** 상태면 실행되지 않습니다. 절전에서 깨우기가 안 되면 Windows 전원 옵션의 "절전 모드 해제 타이머 허용"을 켜 주세요.
- 이 방식은 사용자 비밀번호를 저장하지 않습니다(Windows의 S4U 방식).

## 5. 설정 변경 · 제거

- 시각·끼니·카톡 설정 변경: `install.cmd` 다시 실행
- 제거: `uninstall.cmd` 실행(예약 작업과 카카오 로그인 정보 삭제, '로그인 없이 실행'을 켰다면 관리자 승인 필요) → 폴더 삭제

## 6. 문제 해결

| 증상 | 확인할 것 |
|------|-----------|
| 메모장에 "자동 추출에 실패했습니다"만 뜸 | `logs\` 최신 로그 확인. 대부분 Claude Code 로그인이 풀린 경우 → 터미널에서 `claude` 실행해 다시 로그인 |
| 제1학생식당이 "식단표 없음" | 주말에는 제1학생식당이 운영하지 않습니다. 평일이면 아직 이번 주 식단표가 안 올라온 것일 수 있습니다. |
| 카톡이 안 옴 | 로그에 `ERROR`가 있는지 확인. `KOE` / `401` 오류면 install.cmd를 다시 실행해 카카오 재인증 |
| 메뉴가 틀림 | 표 판독 오류일 수 있습니다. 메시지의 "식단표 보기"나 출처 링크로 원본을 확인하세요. |

## 7. 주의

- **이 폴더를 다른 사람에게 줄 때는 `.secrets\`, `config.cmd`, `output\`, `logs\`, `_workspace\`를 빼고** 주세요. 특히 `.secrets\`에는 본인 카카오 로그인 정보가 들어 있습니다.
- 식단 정보의 저작권은 GIST에 있습니다. 개인 알림 용도로만 사용하세요.
